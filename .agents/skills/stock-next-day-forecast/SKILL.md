# 个股次日走势预测

## 适用场景

- 用户要求预测某只 A 股下一个交易日的涨跌方向或概率。
- 用户要求结合近期走势、行业消息、突发风险判断次日走势。
- 用户问「明天能不能涨」「现在能不能买」「次日怎么操作」时，给出概率化分析，而不是确定性承诺。

不适用于：港股/美股、日内高频交易、确定性收益承诺、具体买卖点位指令。

## 核心原则

1. **概率而非结论**：只给上涨/下跌概率、可靠性、情景与区间，不给「必涨/必跌」。
2. **数据先行**：先取数，再分析；每个判断尽量落到具体价格、成交量或可核验来源。
3. **事实与推断分离**：新闻、公告是事实；对次日的影响是推断，必须分别标注。
4. **不编造**：找不到的消息、公告、数据就写「未找到可核验信息」，不用常识补全。
5. **置信度可解释**：可靠性由数据完整度、消息质量、信号一致性决定，不能凭感觉给高分。

## 执行流程

### 1. 解析标的与交易日

1. 调用 `mcp__sv-stock__stock_search`，把名称或代码解析成 6 位代码，确认股票名称与上市板块。
   - `stock_search` 返回的 `board` 是上市板块（沪市主板/创业板/科创板/北交所），**不是行业**；行业归属需通过消息检索确认。
2. 用 `mcp__sv-stock__stock_history` 最近几条日线确认最后一个交易日。
3. 推算下一个交易日：
   - 跳过周六、周日；
   - 法定节假日无法从行情接口直接确认时，按工作日推算，并在报告中注明「节假日按工作日假设」；
   - 若当日尚未收盘，明确写「盘中快照，非收盘数据」。

### 2. 采集数据

按需调用以下工具，行情类工具可并行；同一轮内避免重复拉取相同区间。

| 维度 | 工具 | 关键参数 |
|---|---|---|
| 近一年 | `mcp__sv-stock__stock_history` | `period="daily"`，`start_date` 约为今天往前 365 天，`adjust="qfq"`，`limit=300` |
| 近一周 | `mcp__sv-stock__stock_history` | 同上，`start_date` 约为今天往前 10 天，取最近 5 个交易日 |
| 今日 | `mcp__sv-stock__stock_quote` | 传入 6 位代码；读取 `price/change_pct/open/high/low/prev_close/volume/amount/time` |
| 今日分时 | `mcp__sv-stock__stock_history` | `period="5"` 或 `"15"`；只使用有 OHLC 的已完成 bar |
| 大盘环境 | `mcp__sv-stock__market_overview` | 读取 `indices/breadth/turnover` |
| 板块轮动 | `mcp__sv-stock__industry_rank` | 分别取 `direction="top"` 与 `"bottom"`，各 10 条左右 |
| 消息面 | `web_search` | 股票名、行业、产业链、公告、政策、突发事件 |

取数要求：

- 记录每次行情数据的 `source`、`fetched_at` 与延迟说明；不要把延迟数据说成实时逐笔。
- 近一年数据不足（次新股）时，用现有历史，并在可靠性上扣分。
- 分钟线缺失或只有昨日数据时，不强行推断今日尾盘，改用 `stock_quote` 的日内高低与现价位置。

### 3. 五个维度分析

#### 3.1 近一年趋势

从日线计算并简述：

- 区间涨跌幅、52 周最高/最低、当前价在一年区间中的位置（高位/中位/低位）。
- 均线结构：收盘价与 MA20/MA60/MA120 的关系，均线是多头排列、空头排列还是缠绕。
- 趋势阶段：上升、下降、震荡；是否出现放量突破或缩量阴跌。
- 最大回撤与近期波动率，判断是趋势票还是高波动题材票。

结论要落到一句话，例如「近一年上升趋势，但当前位于区间上部且偏离 MA20 较大，短线追高性价比一般」。

#### 3.2 近一周走势

- 最近 5 个交易日的累计涨跌幅、上涨/下跌天数。
- 成交量相对 20 日均量的放大或萎缩倍数。
- 关键支撑/阻力：最近 5–10 个交易日的低点、高点、缺口、整数关口。
- 形态：放量突破、缩量回调、冲高回落、横盘整理。

#### 3.3 今日走势

- 开盘价相对昨收的缺口；现价在今日 `[low, high]` 区间的位置：
  `close_position = (price - low) / (high - low)`（区间为 0 时不计算）。
- 尾盘强弱：若有 5/15 分钟线，观察最后 30–60 分钟的 direction 与成交量；没有则明确写「缺少分时数据」。
- 成交额相对近 5 日/20 日均值的变化，判断是放量上攻、放量下跌还是缩量整理。
- 是否触及涨跌停、是否出现长上影/长下影、是否跳空。

#### 3.4 产业消息面

用 `web_search` 至少检索以下方向，并交叉验证：

1. `<股票名> 公告 <当前年月>`
2. `<股票名> 业绩预告 业绩快报 <当前年月>`
3. `<所属行业> 政策 订单 价格 <当前年月>`
4. `<产业链环节> 景气度 供需 <当前年月>`
5. `<股票名> 研报 评级 <当前年月>`

来源优先级：

1. 交易所/公司公告、部委与行业协会文件；
2. 主流财经媒体；
3. 券商研报摘要；
4. 自媒体与论坛——只能作为线索，不能单独支撑结论。

每条消息记录：标题、来源、发布日期、事实/传闻、影响方向（利好/利空/中性）、影响周期（1–4 周/更久）、强度（强/中/弱）。

判断规则：

- 只有**未来 1–4 周内**、且来源可核验的催化，才计入次日概率的加减分。
- 超过 30 天的消息视为背景，不当作新催化。
- 无法确认日期或来源的消息，标注「未核实」，权重减半或不计。
- 没有找到可靠消息时，明确写「未找到可核验的近期催化」，不要用行业常识虚构利好。

#### 3.5 突发情况

检索并评估：

- 减持、解禁、股权质押、诉讼、立案调查、监管问询、业绩爆雷、事故、停牌、重组等。
- 价格/成交异动：涨跌幅接近涨跌停、成交额超过 20 日均值 2 倍、跳空超过 3%、连续放量下跌。
- 宏观或行业突发事件：政策转向、原料价格剧烈波动、海外制裁、汇率/利率突变。

输出格式：`事件 → 发生概率（低/中/高）→ 影响方向 → 影响幅度（小/中/大）→ 依据`。

### 4. 概率与可靠性校准

#### 4.1 上涨/下跌概率

以 50% 为基准，逐项加减，最终限制在 **20%–80%**，并保证上涨 + 下跌 = 100%。

| 因子 | 观察 | 调整 |
|---|---|---|
| 近一年趋势 | 站上 MA60、创新高、均线多头 | +8 |
| 近一年趋势 | 跌破 MA60、创新低、均线空头 | -8 |
| 近一周动量 | 5 日累计上涨且放量 | +7 |
| 近一周动量 | 5 日累计下跌且放量 | -7 |
| 今日强弱 | 现价（或收盘价）位于日内高位、尾盘走强 | +6 |
| 今日强弱 | 现价（或收盘价）位于日内低位、尾盘跳水 | -6 |
| 大盘/板块 | 上涨家数占比 > 60%，板块居涨幅榜 | +5 |
| 大盘/板块 | 上涨家数占比 < 40%，板块居跌幅榜 | -5 |
| 产业催化 | 1–4 周内有可核验利好 | +8 |
| 产业催化 | 1–4 周内有可核验利空 | -8 |
| 突发风险 | 存在中/高概率负面事件 | -5 至 -10 |
| 突发利好 | 存在已证实重大利好 | +5 |

补充规则：

- 传闻按同方向权重的一半计算；无法核实则不计。
- 多个因子指向同一方向时，不要简单叠加到极端，最终仍受 20%–80% 约束。
- 概率是主观综合判断，不是经过统计校准的模型输出，报告中要说明这一点。

#### 4.2 结论可靠性

从 50% 起算，按证据质量加减，最终限制在 **30%–85%**：

| 条件 | 调整 |
|---|---|
| 近一年、近一周、今日三类数据齐全 | +10 |
| 消息面有至少 2 个可核验来源且带日期 | +10 |
| 趋势、周内、今日信号方向一致 | +10 |
| 行情数据为当日且延迟可接受 | +5 |
| 缺少分时数据 | -10 |
| 未找到可核验消息 | -10 |
| 消息过期（> 30 天）或来源单一 | -5 |
| 信号互相冲突 | -10 |
| 存在高不确定性突发事件 | -10 |

可靠性低于 50% 时，报告开头标注「低置信度，仅作情景参考」，并说明主要缺口。

### 5. 输出

先给结论，再给论据。使用 Markdown，中文，简洁，不用表情符号。

必须包含：

1. 标的、下一个交易日、数据时间。
2. 上涨/下跌概率与可靠性。
3. 3–5 条核心理由，每条引用具体数据或来源。
4. 三种情景与关键价位。
5. 失效条件。
6. 数据缺口、来源日期与免责声明。

情景概率要求：

- 上涨情景的概率之和等于总上涨概率，下跌情景的概率之和等于总下跌概率。
- 情景区间用价格区间或百分比区间，不给单点目标价。
- 关键价位来自近期高低点、缺口、均线或整数关口，并说明依据。

## 边界与异常

| 情况 | 处理 |
|---|---|
| 停牌 | 不预测次日方向，说明停牌原因与复牌不确定性 |
| 次新股，历史不足一年 | 用现有数据，可靠性扣 10，并注明样本不足 |
| ST/*ST | 涨跌停幅度按 5% 处理，情景区间相应收窄 |
| 创业板/科创板/北交所 | 涨跌停幅度按 20%/30% 处理，波动区间放宽 |
| 一字涨停/跌停 | 提示次日开板与回封的不确定性，概率向当前方向倾斜但不超过 80% |
| 分钟数据缺失 | 用 `stock_quote` 的日内高低与现价位置替代，可靠性扣分 |
| 工具调用失败 | 重试一次；仍失败则记录数据缺口，不用推测填补 |
| 非交易日提问 | 明确分析的是下一个交易日，并注明节假日假设 |

## 禁止事项

- 不编造新闻、公告、研报、日期或数据。
- 不把传闻、标题党或单一自媒体来源当作事实。
- 不承诺「必涨」「稳赚」「锁定收益」。
- 不给具体买卖指令、仓位比例或杠杆建议。
- 不把可靠性与上涨概率混为一谈：可靠性描述证据质量，概率描述方向判断。
- 不输出与 A 股交易规则冲突的建议（如 T+0 当日卖出）。
