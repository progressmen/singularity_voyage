# 个股基本面深度调研

## 适用场景

- 用户要求对某只股票做深度调研、基本面分析或价值投资判断。
- 用户要求判断「值不值得长期持有」「有没有雷」「现在贵不贵」。
- 用户要求输出一份可复核的调研底稿、投资备忘录或首次覆盖材料。

不适用于：次日涨跌预测（用 `stock-next-day-forecast`）、纯技术面择时、确定性收益承诺、具体买卖点位与仓位指令。

## 核心原则

1. **先排雷，后讲故事**：财务质量不过关，赛道逻辑再美也直接降级。
2. **现金流优先于利润**：扣非净利润要和经营现金流对照看，长期背离是首要红旗。
3. **数据可溯源**：每个关键数字标注报告期与来源；缺失就写「未获取」，不估算填补。
4. **事实、推断、待验证三分**：公告与财报是事实，产业链判断是推断，草根信息是待验证。
5. **结论可反驳**：必须给出失效条件与跟踪指标，而不是只给看多理由。
6. **不给单点目标价**：给合理价值区间、三套情景假设与悲观底线。
7. **优先级固定**：赛道景气 → 商业模式 → 财务质量 → 管理层 → 产业链 → 估值 → 风险。

## 执行流程

### 第 0 步：界定标的与任务

1. 用 `mcp__sv-stock__stock_search` 把名称或代码解析为 6 位代码，确认名称与上市板块。
   - `board` 是上市板块（沪市主板/创业板/科创板/北交所），不是行业；行业归属通过主营构成与消息检索确认。
2. 明确调研目的与期限，缺省时按「首次覆盖、3 年视角」处理：
   - 首次覆盖 / 持仓复核 / 排雷专项；
   - 投资期限 1 年以内、1–3 年、3 年以上。
3. 记录数据截止日，并在报告开头注明。

若标的、目的、期限都不明确，先用 AskUserQuestion 确认，不要凭猜测开工。

### 第 1 步：采集数据

行情类工具可并行，同一轮内不要重复拉取相同区间。

| 用途 | 工具 / 来源 | 关键参数与读法 |
|---|---|---|
| 标的识别 | `mcp__sv-stock__stock_search` | `keyword` 传名称或代码 |
| 估值位置辅助 | `mcp__sv-stock__stock_history` | `period="weekly"`，`start_date` 往前 5–10 年，`adjust="qfq"`；算股价分位，不等于估值分位 |
| 当前状态 | `mcp__sv-stock__stock_quote` | 现价、涨跌幅、成交额；换手率/PE/市值可能缺失 |
| 同业与可比 | `mcp__sv-stock__stock_quote` | 一次最多 20 只，同业 3–5 家，用于横向对比股价表现 |
| 大盘与行业环境 | `mcp__sv-stock__market_overview`、`mcp__sv-stock__industry_rank` | 判断市场情绪与板块轮动，只作背景 |
| 三张报表与业务拆分 | 年报/半年报/季报、交易所与巨潮公告 | 用户上传的年报 PDF 优先直接用 Read 读取，标注页码或章节 |
| 治理与股东 | 年报「公司治理」「股东情况」、公告、问询函回复 | 质押、减持、定增、激励、诉讼、处罚 |
| 行业与产业链 | `web_search`，行业协会、券商行业报告、价格与开工数据 | 至少 2 个独立来源 |
| 券商预测 | `web_search` | 至少 2 家，记录预测年度、机构、日期 |

取数规则：

- 财务数据以最近一期定期报告为准，跨期对比用同一口径（单季 vs 单季、累计 vs 累计）。
- 行情数据只用于估值位置与异动背景，不能替代基本面结论。
- 每条关键数据记录「数值 + 报告期 + 来源」。
- 未获取到的数据写「未获取」；可以给同行参考值，但必须标明是同行而非本公司。
- 港股/美股：行情工具只覆盖 A 股，只能基于公开资料做定性调研，并单列数据限制。

### 第 2 步：九维分析

每个维度都要给出「检查项 → 证据 → 判断」，不能只罗列数据。

#### 2.1 行业与赛道

检查项：

- 赛道空间：市场规模、增速、渗透率，是增量市场还是存量内卷。
- 行业周期：成长/成熟/衰退/强周期；政策周期、产能周期、库存周期所处位置。
- 竞争格局：CR3/CR5、集中度变化、新进入者威胁。
- 核心壁垒：技术专利、牌照资质、规模成本、渠道、品牌、资源、客户粘性。
- 政策与外部约束：监管、补贴、能耗、关税、环保、集采、反垄断。
- 供需结构：产能投放节奏、下游需求来源（地产/车企/AI/海外等）。

红旗：行业增速低于 GDP 且产能仍在扩张；补贴退坡或集采压价；新进入者大量涌入；需求高度依赖单一下游。

输出：一句话「土壤」判断 + 景气度 1–5 分，并说明依据。

#### 2.2 商业模式

检查项：

- 主营业务拆解：分产品/分业务收入与毛利占比，哪块是基本盘，哪块是第二曲线。
- 收入结构：国内/海外占比，前五大客户集中度。
- 成本结构：原材料、人工、制造、运费；上游大宗是否为成本命门。
- 模式：To B / To C / 平台；直销/经销；一次性收入还是订阅复购。
- 产能：布局、利用率、扩产计划、资本开支节奏。
- 产品迭代：新品管线、研发方向、换代周期。

红旗：单一客户收入占比超过 30%；经销占比高且终端不透明；扩产幅度远超需求增速；第二曲线长期不贡献利润。

输出：一句话说清「靠什么赚钱、赚得稳不稳」。

#### 2.3 财务体检（重中之重）

先看利润质量，再看资产负债，最后看现金流。

**盈利**

| 指标 | 看什么 | 警戒信号 |
|---|---|---|
| 营收增速 | 三年趋势、单季趋势 | 连续 2 个季度失速且无解释 |
| 扣非净利润增速 | 与营收增速匹配度 | 营收增长但扣非下滑 |
| 归母与扣非差额 | 非经常性损益占比 | 扣非/归母 < 70% 且连续两年 |
| 毛利率 | 趋势 + 同行对比 | 两年累计下滑超过 5pct |
| 净利率 | 费用侵蚀情况 | 毛利稳定但净利率持续下降 |
| 四费率 | 销售/管理/研发/财务 | 销售费用增速持续高于营收 |
| 非经常性损益 | 补贴、处置、理财收益 | 利润主要靠补贴或资产处置 |

**资产负债**

- 资产负债率、有息负债规模、货币资金 vs 短期借款。
- 商誉、在建工程、其他应收款、预付款：高危藏雷科目，逐项说明形成原因。
- 存货：规模、周转天数、跌价准备；周期股重点看存货与价格。
- 应收账款：周转天数、账龄结构、坏账计提比例、是否集中于大客户。

**现金流**

- 经营活动现金流净额（OCF），以及与扣非净利润的匹配度。
- 资本开支：维持性 vs 扩张性；自由现金流（FCF = OCF − CAPEX）。
- 分红、回购、股利支付率。

**质量红线表**（通用阈值；金融、地产、公用事业等特殊行业改用行业口径并注明）

| 检查项 | 警戒线 | 含义 |
|---|---|---|
| 扣非 / 归母 | < 70% 连续两年 | 利润依赖非经常性损益 |
| OCF / 扣非（3 年累计） | < 0.8 | 利润没有变成现金 |
| 应收增速 − 营收增速 | > 10pct | 放宽信用换收入 |
| 存货增速 − 营收增速 | > 15pct | 滞销或跌价风险 |
| 商誉 / 净资产 | > 30% | 减值风险 |
| 有息负债 / EBITDA | > 4 | 偿债压力 |
| 货币资金 / 短期借款 | < 1 | 短债缺口 |
| 毛利率两年累计变动 | < −5pct | 竞争格局恶化 |
| ROIC − WACC | < 0 | 规模扩张毁灭价值 |
| 大股东质押比例 | > 50% | 治理与平仓风险 |

**同行对比**：至少选 3 家可比公司，对比增速、毛利率、周转、ROE、ROIC，判断是龙头还是平庸企业。同行数据缺失时标注「未获取」，不用行业均值冒充。

输出：财务评分 1–5 分 + 命中了几条红线 + 一句话结论（如「利润含金量尚可，但应收增速连续两年高于营收，需跟踪回款」）。

#### 2.4 管理层与治理

检查项：

- 实控人与股权结构：持股比例、质押、减持、定增、股权激励。
- 管理层背景：从业年限、行业资历、过往履历与口碑。
- 战略一致性：近 3 年年报与电话会口径是否反复摇摆。
- 诚信记录：历史处罚、问询函、财务更正、内幕交易、诉讼。
- 激励机制：考核目标是否与业绩强绑定，还是轻松达成。

红旗：频繁跨界并购、追逐概念；高质押叠加连续减持；财务更正或审计意见异常；激励目标明显低于历史增速。

输出：治理评分 + 一句话定性。

#### 2.5 产业链验证

- 上游：供应商集中度、议价能力、是否卡脖子、涨价能否传导。
- 下游：下游景气度、在手订单、回款难度。
- 对手：对手财报、扩产计划、报价、渠道、新品，价格战风险。
- 渠道与终端：动销、库存、折扣、拿货意愿（草根信息最值钱，但要标为待验证）。

每条信息标注来源类型：公司公告 / 行业数据 / 经销商访谈 / 媒体 / 推断。只有一手或可核验来源才能支撑核心结论。

#### 2.6 估值与安全边际

1. 指标选择：
   - 稳定盈利：PE（TTM/动态）、PEG；
   - 周期股：PB + PE 历史分位；
   - 亏损或利润失真：PS、EV/EBITDA、单位经济模型。
2. 历史分位：当前估值在自身 5/10 年区间的分位。
   - 若没有 PE/PB 历史序列，**不得编造分位**；改用股价分位 + 盈利变化做近似，并明确标注「近似，非估值分位」。
3. 可比公司：3–5 家，列 PE、PB、增速、ROE，说明为什么可比。
4. 三情景盈利预测：保守 / 中性 / 乐观，写清量、价、毛利率、费用率假设，可复算。
5. 安全边际：合理价值区间 + 悲观情景底线；反推现价隐含的增长预期。

红旗：估值分位超过 80% 且盈利预期在下修；靠一次性收益压低 PE；周期股用景气顶部利润算 PE；可比公司刻意挑选。

输出：估值评分 + 合理价值区间 + 现价所处位置（低估/合理/偏贵/无法判断）。

#### 2.7 风险清单

按六类逐项筛查，只写本标的真实存在的风险：

| 类型 | 需要确认的内容 |
|---|---|
| 业绩风险 | 需求下滑、价格下跌、毛利率下滑、订单不及预期 |
| 财务风险 | 现金流恶化、债务到期、大额减值、关联交易 |
| 政策风险 | 监管收紧、补贴退坡、集采、出口限制 |
| 竞争风险 | 新玩家、技术替代、价格战 |
| 治理风险 | 实控人风险、大额减持、股权纷争 |
| 黑天鹅 | 自然灾害、地缘冲突、大客户流失 |

每条按「事件 → 概率（低/中/高）→ 影响（小/中/大）→ 触发信号」输出，并标注对应章节证据。

#### 2.8 跟踪信号

| 频率 | 指标 |
|---|---|
| 月度 | 订单、开工率、产品报价、渠道库存与动销、关键大宗价格 |
| 季度 | 营收与扣非增速、毛利率、OCF、应收与存货周转、机构持仓变化 |
| 事件 | 调研纪要、产能投产、重大合同、减持与解禁、诉讼与处罚 |
| 口径 | 电话会与年报措辞是否变化（如从「全力扩张」转为「稳健经营」） |

必须给出「建仓后一个季度内必须复核的 3 个指标」及各自预警阈值。

#### 2.9 评分与结论

加权百分制（分项 1–5 分，换算为百分制后加权）：

| 模块 | 权重 |
|---|---|
| 行业与赛道 | 15 |
| 商业模式 | 15 |
| 财务质量 | 25 |
| 管理层与治理 | 10 |
| 产业链验证 | 10 |
| 估值与安全边际 | 15 |
| 风险 | 10 |

评级映射：

- 80 分以上：优质，可纳入跟踪池；
- 65–79：合格，需等待估值或某项改善；
- 50–64：有明显短板，观察为主；
- 50 以下：回避。

评分是结构化辅助，不是精确模型；每个分项必须给一句依据。命中 2 条以上财务红线的，财务分不得高于 2 分。

结论必须包含：一句话判断、三条核心逻辑、三条主要风险、合理价值区间、失效条件、下一步跟踪指标。

### 第 3 步：交叉验证

- 财务增长 vs 产业链证据：收入增长是否有订单、价格、产能支撑。
- 公司口径 vs 对手口径：同一行业数据是否互相印证。
- 券商预测 vs 公司指引 vs 历史完成率：判断预测是否乐观。
- 关键结论至少 2 个独立来源；冲突时并列呈现并说明取舍，不要只选支持自己观点的那个。

### 第 4 步：输出

先给结论卡片，再展开底稿。默认在对话中以 Markdown 输出；内容较长或用户要求文件时，保存为 Markdown 文件并说明路径。

## 输出前自检

- 每个财务数字都有报告期。
- 每个关键判断都有来源，或明确标注「推断」。
- 风险是针对本标的的，不是通用模板。
- 三情景假设可以复算，价值区间与假设一致。
- 没有编造估值分位、目标价、研报观点或管理层表态。
- 评分与结论方向一致，红线数量与财务得分不矛盾。
- 数据缺口已单列，并在结论中体现置信度。

## 边界与异常

| 情况 | 处理 |
|---|---|
| 港股/美股 | 行情工具不覆盖，只能做定性调研；所有行情与估值标注外部来源与缺口 |
| 次新股，历史不足 3 年 | 用上市以来数据，标注样本不足，估值分位不下结论 |
| ST/*ST | 先查退市与持续经营风险，财务红线权重加倍 |
| 金融/地产/公用事业 | 改用行业口径（PB、拨备覆盖率、NAV、产能成本曲线），不套通用阈值 |
| 亏损公司 | 不用 PE，改 PS、EV/Sales 或单位经济模型 |
| 强周期股 | 用中枢利润与 PB 分位，不用景气顶部利润估值 |
| 数据缺失 | 写「未获取」，降低置信度，不估算填补 |
| 用户只要结论 | 先给结论卡片，再询问是否展开完整底稿 |
| 用户上传年报 | 优先使用文件数据，标注页码或章节 |
| 工具调用失败 | 重试一次；仍失败则记录缺口，不用推测替代 |

## 禁止事项

- 不编造财务数据、公告、研报评级、目标价或管理层言论。
- 不用行业均值替代公司缺失数据而不标注。
- 不把传闻、自媒体或单一来源当作事实。
- 不承诺收益，不给买卖点位、仓位比例或杠杆建议。
- 不把短期股价走势当成基本面结论。
- 不省略风险只讲逻辑，也不为凑字数堆砌通用风险。
