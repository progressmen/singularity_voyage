数据与备份

备份为单个 JSON 文件，含记忆、待办、收件箱、知识库、自动化与会话投影； 不含 API Key / SMTP 密码，也不含 dsh 原始会话日志（`.dsh/sessions` 或 Postgres）。

备份与恢复

清空数据

清空只影响本产品的数据文件；config.json（密钥）与 dsh 原始会话日志不受影响。
